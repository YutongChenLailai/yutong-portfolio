# PoopSlaves Portfolio Website

Responsive portfolio case study adapted from Figma node `8:2028`.

## Preview

```bash
python3 -m http.server 4173 -d portfolio-site
```

Open `http://localhost:4173`.

## Publish with GitHub Pages

1. Create a repository and push the contents of this folder.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`.

The site is plain HTML/CSS/JavaScript and needs no build step.
